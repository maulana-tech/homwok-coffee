# 4.2.1 Implementasi Data Awal (Database Seeder)

Untuk keperluan pengujian fungsional maupun demonstrasi sistem, disusun berkas *seeder* Laravel yang mengisi basis data fisik dengan data awal yang merepresentasikan kondisi operasional nyata Homwok Coffee. Pengisian data awal ini dikonfigurasi melalui tiga berkas penabur data (*seeder*) utama:

### 1. MenuSeeder
MenuSeeder berfungsi melakukan injeksi data awal berupa 89 rekaman katalog produk minuman yang bersumber langsung dari papan menu operasional Homwok Coffee. Varian menu yang memiliki pilihan ukuran saji (seperti Reguler dan Large) dipisahkan menjadi entri baris data (*record*) mandiri agar masing-masing ukuran dapat dikaitkan dengan rincian formulasi resep HPP serta harga jual spesifik yang berbeda. Nilai nominal harga pada menu operasional (yang tercantum dalam format ribuan) dikonversikan dengan pengali 1.000 ke dalam basis data agar tersimpan secara penuh dalam satuan mata uang Rupiah bulat.

### 2. BahanBakuSeeder
BahanBakuSeeder menginjeksi 59 entri data induk (*master data*) bahan baku yang diklasifikasikan ke dalam beberapa kategori utama, seperti kopi, susu, sirup, bubuk perasa, buah segar, roti, saus, serta bahan kemasan. Pada *seeder* ini, sistem secara otomatis menyertakan satu transaksi pembelian pengadaan awal berskala simulasi dengan nama "Stok Awal". Logika ini dirancang agar setiap entri bahan baku memiliki minimal satu lot persediaan aktif pertama pada tabel detail pembelian. Dengan demikian, antrean lot awal tersebut langsung siap dikonsumsi sebagai bahan baku pembanding saat pengujian kalkulasi algoritma FIFO dijalankan pertama kali.

Berikut merupakan implementasi penulisan struktur kelas seeder pada berkas `BahanBakuSeeder.php` yang ditunjukkan pada Listing 4.0.2:

            ['Cookies', 'gram', 40],
            ['Bubuk Avocado', 'gram', 60],
            ['Bubuk Thai Tea', 'gram', 35],

            ['Teh', 'gram', 30],
            ['Soda', 'ml', 12],

            // Buah segar

        // Header pembelian "Stok Awal".
        $idManager = Pegawai::where('peran', 'manager')->value('id_pegawai')
            ?? Pegawai::value('id_pegawai');

        $tglStok = date('Y-m-d', strtotime('-7 days'));
        $pembelian = Pembelian::create([

                ['nama_bahan' => $nama],
                ['satuan' => $satuan, 'stok_minimum' => self::STOK_MIN[$satuan]],

            // Hanya beri lot stok awal untuk bahan yang baru dibuat.

                'sisa_qty' => $qty,
                'harga_beli' => $harga,
                'tanggal_kadaluarsa' => null,
            ]);
            $total += $qty * $harga;
        }

        $pembelian->update(['total_beli' => $total]);
    }
}

### 3. ResepSeeder
ResepSeeder mengelola pemetaan dekomposisi relasional formulasi resep sebanyak kurang lebih 349 baris data yang mencakup kebutuhan takaran bahan untuk seluruh katalog menu. Guna mempercepat pembentukan data, sistem dikonfigurasi untuk secara otomatis mengalikan takaran bahan dasar menu berukuran Large sebesar 1,3 kali dari takaran standar ukuran Reguler. Di samping itu, *seeder* ini juga secara otomatis menyisipkan komponen kemasan produk (seperti *paper cup*, botol, atau *box snack*) ke dalam rincian resep berdasarkan kategori masing-masing menu.

Berikut merupakan struktur potongan kode program formulasi relasi menu ke resep bahan baku pada berkas `ResepSeeder.php` yang ditunjukkan pada Listing 4.0.3:

**Listing 4.0.3 Struktur Relasi Menu dan Resep Bahan Baku pada ResepSeeder.php**
```php
<?php

namespace Database\Seeders;

use Illuminate\Database\Seeder;
use App\Models\Menu;
use App\Models\BahanBaku;
use App\Models\Resep;

class ResepSeeder extends Seeder
{
    /** Faktor takaran untuk ukuran Large. */
    private const FAKTOR_L = 1.3;

    /** Nama bahan basis kopi & susu yang dipakai berulang. */
    private const KOPI = 'Biji Kopi Arabika';
    private const SUSU = 'Susu Segar (Fresh Milk)';
    private const AREN = 'Sirup Gula Aren';

    public function run(): void
    {
        // base name => [[nama_bahan, takaran Reguler], ...] (tanpa kemasan)
        $resep = [
            // Coffee
            'Cappuccino' => [[self::KOPI, 18], [self::SUSU, 150]],
            'Espresso' => [[self::KOPI, 18]],
            'Homwok Original' => [[self::KOPI, 18], ['Susu Kental Manis', 20], [self::SUSU, 120]],
            'Homwok Signature' => [[self::KOPI, 18], ['Brown Sugar', 15], [self::SUSU, 120]],
            'Hawaiian Coffee' => [[self::KOPI, 18], ['Santan (Coconut Milk)', 120]],
            'Sweet Black' => [[self::KOPI, 18], ['Simple Syrup', 15]],
            'Homwok Booster' => [[self::KOPI, 36], ['Susu Kental Manis', 20], [self::SUSU, 120]],

            // Flavoured Coffee (espresso + sirup + milk)
            'Hazelnut' => [[self::KOPI, 18], ['Sirup Hazelnut', 20], [self::SUSU, 120]],
            'Caramel' => [[self::KOPI, 18], ['Sirup Caramel', 20], [self::SUSU, 120]],
            'Coca Rum' => [[self::KOPI, 18], ['Sirup Coca Rum', 20], [self::SUSU, 120]],
            'Regal Coffee Rum' => [[self::KOPI, 18], ['Sirup Coca Rum', 20], ['Biskuit Regal', 15], [self::SUSU, 120]],
            'Salted Caramel' => [[self::KOPI, 18], ['Sirup Salted Caramel', 20], [self::SUSU, 120]],
            'Irish' => [[self::KOPI, 18], ['Sirup Irish', 20], [self::SUSU, 120]],
            'Peanut Butter Cookies' => [[self::KOPI, 18], ['Sirup Peanut Butter', 20], ['Cookies', 15], [self::SUSU, 120]],
            'Avocado Coffee' => [[self::KOPI, 18], ['Bubuk Avocado', 20], [self::SUSU, 120]],

            // Mocktail
            'Sparkling Yellow' => [[self::KOPI, 18], ['Sirup Pineapple', 20], ['Soda', 120]],
            'Tropical Fizzy' => [[self::KOPI, 18], ['Sirup Tropical', 20], ['Soda', 120]],
            'Strawberry Rock' => [[self::KOPI, 18], ['Sirup Special', 20], ['Buah Strawberry Segar', 30]],
            'Mango Fizz' => [[self::KOPI, 18], ['Sirup Mango', 20], [self::SUSU, 120]],
            'Mango Peach' => [['Soda', 120], ['Sirup Mango', 20], ['Buah Peach Segar', 30]],
            'Sparkling Berry' => [['Soda', 120], ['Buah Strawberry Segar', 30], ['Sirup Strawberry', 20]],
            'Apple Mojito' => [['Soda', 120], ['Sirup Apple', 20], ['Sirup Special', 10]],

            // Non Coffee
            'Thai Tea' => [['Bubuk Thai Tea', 20], ['Creamer', 10], [self::SUSU, 120]],
            'Taro' => [['Bubuk Taro', 25], [self::SUSU, 150]],
            'Red Velvet' => [['Bubuk Red Velvet', 25], [self::SUSU, 150]],
            'Regal Rum' => [['Rum (Essence)', 10], ['Biskuit Regal', 20], [self::SUSU, 150]],
            'Oreo Blend' => [['Oreo', 30], [self::SUSU, 150]],
            'Matcha Latte' => [['Bubuk Matcha', 8], [self::SUSU, 150]],
            'Original Choco' => [['Bubuk Coklat', 25], [self::SUSU, 150]],
            'Avocado Choco' => [['Bubuk Avocado', 15], ['Bubuk Coklat', 15], [self::SUSU, 150]],

            // Fruit Series
            'Lychee Tea' => [['Sirup Lychee', 20], ['Teh', 5], ['Buah Lychee', 30]],
            "Passionate'a" => [['Sirup Passion Fruit', 20], ['Teh', 5], ['Buah Peach Segar', 30]],
            'Red Sunrise' => [['Sirup Mango', 20], ['Sirup Special', 10], ['Buah Peach Segar', 30]],
        ];

        // Kategori yang memakai paper cup (minuman gelas).
        $kategoriGelas = ['Coffee', 'Flavoured Coffee', 'Mocktail', 'Non Coffee', 'Fruit Series'];

        // Peta bahan (nama -> model) untuk ambil id + satuan.
        $bahanMap = BahanBaku::all()->keyBy('nama_bahan');

        $baris = [];
        foreach (Menu::all() as $menu) {
            $nama = $menu->nama_menu;
            if (str_ends_with($nama, ' (L)')) {
                $ukuran = 'L';
                $base = substr($nama, 0, -4);
            } elseif (str_ends_with($nama, ' (R)')) {
                $ukuran = 'R';
                $base = substr($nama, 0, -4);
            } else {
                $ukuran = 'S';
                $base = $nama;
            }

            if (! isset($resep[$base])) {
                continue;
            }

            // Bahan konsumsi (takaran L = x1,3).
            foreach ($resep[$base] as [$namaBahan, $takaran]) {
                $b = $bahanMap->get($namaBahan);
                if (! $b) {
                    continue;
                }
                $qty = $ukuran === 'L' ? (int) round($takaran * self::FAKTOR_L) : $takaran;
                $baris[] = [
                    'id_menu' => $menu->id_menu,
                    'id_bahan' => $b->id_bahan,
                    'takaran' => $qty,
                    'satuan' => $b->satuan,
                    'created_at' => now(),
                    'updated_at' => now(),
                ];
            }

            // Kemasan otomatis.
            $kemasan = match (true) {
                in_array($menu->kategori, $kategoriGelas, true) => $ukuran === 'L' ? 'Paper Cup 16oz' : 'Paper Cup 12oz',
                $menu->kategori === 'Botol 1 Liter' => 'Botol 1 Liter',
                $menu->kategori === 'Rice Bowl' => 'Box Rice Bowl',
                default => 'Box Snack',
            };
            if ($bk = $bahanMap->get($kemasan)) {
                $baris[] = [
                    'id_menu' => $menu->id_menu,
                    'id_bahan' => $bk->id_bahan,
                    'takaran' => 1,
                    'satuan' => $bk->satuan,
                    'created_at' => now(),
                    'updated_at' => now(),
                ];
            }
        }

        // Bulk insert resep.
        foreach (array_chunk($baris, 200) as $chunk) {
            Resep::insert($chunk);
        }
    }
}
```

---

Penyediaan data awal melalui *Database Seeder* yang menggunakan data operasional riil (bukan menggunakan data sampel acak atau generik) bertujuan agar seluruh hasil analisis pengujian sistem pada Subbab 4.6 memiliki relevansi dan akurasi praktis terhadap kondisi nyata di kedai Homwok Coffee, sekaligus memudahkan proses verifikasi manual serta pencocokan nilai perhitungan HPP oleh sistem dengan kalkulasi manual sebagai standar pembanding yang sah.
